앞으로

누가 대상인지, 완료했는지, 오늘 어떤 일정이 있는지만 정확히 알려줍니다. 공단 판단은 공단에 맡깁니다.

최종 모습: 사람 자료 + 계획일정 + 실제 태그를 연결해, 놓치기 쉬운 업무를 자동으로 알려주고 완료 여부만 관리합니다.

지금

앞으로

작업영역을 채우는 한 달 달력에 월 1회 방문·마감·연차·개인일정을 표시합니다. 월간 칸을 누르면 3주로 확대하고 우클릭하면 월간으로 돌아옵니다.

앞으로

모든 로그인 사용자가 계획 Excel을 가져오고 전체 수급자–요양보호사 일정을 생성·조회·수정·삭제합니다. 일시 대체는 요양보호사 일반 수정이며 모든 변경을 기록합니다.

앞으로

센터장 전용 계정관리·감사로그와 센터정보·센터 한마디를 만듭니다. ADMIN의 직원 연결은 최초 설치 때 이미 끝나므로 표시만 하고, 사용중지는 계정삭제가 아니라 로그인을 막고 기존 세션을 끝냅니다.

제거·재작성
지금

앞으로

인정전환은 제거합니다. 옛 W2는 데이터 유무를 확인한 뒤 비활성화하고 반기 대상자·완료 기능으로 바꿉니다.

본인부담금·OCR·일반 입출력 메뉴는 없애는 것이 아니라 이번 상세 재설계에서 잠시 제외한 것입니다.

앞으로 지킬 최소 규칙

화면에 필요한 것만 남깁니다

대상자·완료 화면

  • 업무분류를 누르면 해당 대상자만 보입니다.
  • 대상자명과 완료 여부가 중심입니다.
  • 완료 처리·완료 취소는 버튼으로 합니다.
  • 누가 언제 바꿨는지는 화면이 아니라 감사로그에 남깁니다.

자동 업무카드

  • 대상자·업무명·마감 또는 D-day·완료만 표시
  • 계약만료·인정만료·반기평가·직원교체 네 종류부터
  • 원천자료에서 계산하고 카드 전용 범용 원장은 만들지 않음
  • 기한이 지나도 미완료이면 사라지지 않음
  • 계약·인정·직원교체는 완료 버튼, 반기평가는 통보일 입력으로 완료

계약·인정·계획서

  • 계약: 서비스 종류·시작일·종료일·종료사유
  • 인정번호·인정기간·등급 기록은 유지
  • 인정전환 일괄기능은 제거
  • 반기평가 = 급여계획 대상자와 완료 관리
  • 권장기한은 6개월 월말·인정만료·계약만료 중 가장 빠른 날

자동 알림

  • 계약만료 D-45
  • 인정만료 D-100
  • 반기평가 실제 권장기한 D-45
  • 직원교체 실제 첫 제공일부터 14일
  • 업무카드 완료 시 달력 마감도 함께 완료

만들지 않을 것

  • 공단이 하는 계약·인정 적합성 재검증
  • 상담내용·면제사유 같은 불필요한 상세기록
  • 여러 단계·여러 상태를 가진 업무 절차
  • 체크박스 — 보호자를 납부자로 고를 때만 예외

리스트와 카드는 다릅니다. 수급자·직원 완료현황에는 대상자와 완료만 보여주고, 자동 업무카드에는 잊지 않기 위해 업무명과 마감일만 더 보여줍니다. 발생이유·담당자·단계·첨부·복수 상태는 만들지 않습니다.

중요: 업무상 계획적용기간은 시작일부터 다음 반기 말일까지이고 인정·계약이 먼저 끝나면 그날까지입니다. 하지만 공단에서 이미 작성·검증하므로 ERP는 그 텍스트를 다시 검사하거나 저장을 막지 않고, 반기평가를 잊지 않게 알리는 계산에만 만료 cap을 씁니다. 반기평가는 별도 완료버튼이 아니라 실제 통보일 입력이 완료 증거입니다.

대시보드 이름과 실제 대상조건

수급자 5개, 직원 6개는 이렇게 봅니다

화면에는 긴 설명을 늘어놓지 않고 대상자와 완료만 보여줍니다. 아래 표는 시스템이 누구를 목록에 넣을지 정하는 내부 기준입니다.

수급자 업무 5개
이름누가 대상인가언제 한 건으로 보는가
상담반영연 1회. 그해 중간에 계약종료 처리된 수급자는 제외수급자 × 연도
반기평가유효 통보 이력이 없으면 우선 미완료. 이력이 있으면 마지막 통보일에서 6개월 되는 달의 말일, 인정·계약 만료가 더 빠르면 그날까지실제 통보일 입력 = 완료 · 별도 완료값 없음
서류미비선택한 월에 수급자–요양보호사 서비스 일정이 하나라도 있는 모든 수급자수급자 × 일정이 있는 월
인정만료현재 적용할 인정 종료일이 100일 안으로 들어온 수급자인정 회차
계약만료현재 적용할 계약 종료일이 45일 안으로 들어온 수급자계약 회차
직원 업무 6개
이름회수한 최소 대상조건완료 판단
보수교육현재 재직 요양보호사 중 대상연도와 출생연도 홀짝이 같고, 최초 요양보호사 자격 취득연도 뒤 2년을 초과한 사람해당 연도 완료 버튼
직원상담분기 첫날부터 말일까지 계속 재직한 요양보호사. 첫날 입사·말일 퇴사는 포함. 화면은 현재 분기를 기본으로 엶해당 분기 완료 버튼
인권교육반기 말일 재직자. 반기 중 입사해도 말일까지 있으면 포함, 말일 전 퇴사는 제외. 같은 반기 재입사는 완료를 이어 씀해당 반기 완료 버튼
연간교육12월 31일 재직자. 그해 중 입사해도 연말까지 있으면 포함. 같은 해 재입사는 기존 완료를 이어 씀. 장애인학대·노인학대·성희롱·직장내괴롭힘·개인정보보호 5과목5과목이 모두 끝나야 완료
건강검진그해 신규입사자는 중도퇴사해도 대상. 기존 직원은 12월 31일 재직 시 대상. 검진일이 입사일보다 1년 초과 오래됐으면 주의검진일 있음 = 완료
신규교육입사·재입사 때마다 새 재직에 1건. 이후 퇴사해도 대상 이력은 지우지 않고 예전 재직 완료도 재사용하지 않음해당 신규 재직 건 완료 버튼

한꺼번에 현재 재직자로 묶지 않습니다. 상담은 분기 전체, 인권교육은 반기 말일, 연간교육은 12월 31일, 건강검진은 신규입사 여부와 12월 31일을 각각 봅니다. 날짜의 첫날과 마지막 날은 모두 포함합니다.

이 조건은 삭제된 구 1.0 정본의 보존된 읽기 기록을 회수하고, 현재 노션의 교육확인·직원상담·건강검진 대상 뷰와 대조했습니다. 노션은 직원상담의 분기 첫날 입사자와 건강검진의 그해 입사 후 중도퇴사자를 빠뜨리므로 그대로 복사하지 않고, 구 정본의 포함 경계와 형님의 최신 결정을 적용합니다. 개인 이름이나 식별값은 넣지 않았습니다.

실제 급여 순서로 만드는 상담 대상

하루 대체근무도 직원교체입니다

배정표가 바뀌었다고 만드는 것이 아니라, 실제로 서비스를 제공한 요양보호사의 순서를 보고 만듭니다.

언제 생기나

  • 수급자·서비스별 직전 실제 제공자와 새 제공자를 비교
  • 빈 날이 있어도 마지막 실제 제공자를 직전 사람으로 사용
  • 하루 대체근무도 같은 규칙

언제까지 하나

  • 새 직원의 첫 실제 제공일이 Day 1
  • 첫 제공일 +13일, 즉 14일 안에 완료
  • 상담내용은 쓰지 않고 완료만 표시

다시 바뀌면

  • Day 14 재교체는 앞 미완료 건을 예외 종결
  • Day 15 이후에는 예외를 적용하지 않음
  • 실제근무 정정·무효화 시 다시 계산

2인 근무는 이렇게

  • 방문요양·방문목욕은 모두 1명 또는 2명 가능
  • 직전 묶음과 비교해 새로 들어온 사람만 대상
  • A+B → A+C이면 C만 직원교체
  • 빠진 사람이나 표시순서 변경만으로는 만들지 않음

계획일정과 태그 Excel

정상일 때만 고치고, 애매하면 “확인요망”

태그를 가져왔다고 무조건 일정을 바꾸지 않습니다. 한 쌍이 분명하고 시간도 정상일 때만 시작·종료를 함께 바꿉니다.

1. 후보 1개만

수급자 + 요양보호사 + 날짜·시간범위를 통과한 계획이 정확히 하나

2. 시작시간 판정

계획시간 앞 30분·유지·뒤 30분 중 하나

3. 서비스시간 계산

태그 종료 − 태그 시작, 30분 단위 내림

4. 한 번에 반영

보정 시작 + 서비스시간 = 보정 종료

종료시간 = 보정 시작시간 + 인정 서비스시간

달력에는 사유를 길게 쓰지 않습니다. 종료 태그 없음, 계획만 있음, 태그만 있음, 1시간 이상 차이, 후보 0개·2개 이상, 30분 미만 서비스는 모두 똑같이 확인요망으로 표시합니다. 두 후보 중 하나가 더 가까워도 자동으로 고르지 않습니다.

원본 보존: 가져온 태그 Excel은 바이트 그대로 두고, 원본 태그값과 일정 수정 전·후를 별도 변경기록으로 남깁니다. 아직 태그를 적용하지 않은 날짜라면 첫 가져오기가 사람이 고친 일정도 보정할 수 있고, 반영 뒤에는 사람이 다시 자유롭게 고칠 수 있습니다.

태그 다시 가져오기: 파일명이 달라도 같은 태그 내용은 중복 적용하지 않습니다. 같은 날짜의 태그가 이미 한 번 적용됐다면 수정된 태그 Excel에 그 날짜가 다시 있어도 건너뛰므로 사람의 이후 수정도 덮지 않습니다. 한 태그 파일에 섞인 새 날짜만 처리합니다.

달력 동작: 같은 사회복지사·수급자·달력월에는 방문일정 1건만 둡니다. 달력은 남는 가로·세로를 채우고, 날짜 칸 클릭으로 해당 주 앞뒤를 포함한 3주를 보며 우클릭으로 같은 사람·같은 달의 월간화면으로 돌아갑니다. 자동 마감은 달력에서 완료하지 않고 업무카드 완료값만 읽습니다.
