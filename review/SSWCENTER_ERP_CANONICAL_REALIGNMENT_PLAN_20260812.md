# SSWCenter ERP 최소기능 정본·테스트 재정렬 계획

> 기준일: 2026-08-12 KST
> 상태: IMPLEMENTATION 전 문서 정렬 계획
> 기준: `SSWCENTER_ERP_MINIMUM_SCOPE_RECLASSIFICATION_20260812.md`
> 금지: 이 계획만으로 제품 코드·DB·migration을 수정하지 않는다.

## 1. 목적

현재 `docs/01~06`과 일부 테스트는 공단 전산 재검증, 다단계 업무카드, 인정전환 일괄기능, 계약 연결형 급여계획서, 복잡한 RFID 보정 등을 아직 정답으로 강제한다.

따라서 제품 구현 전에 다음 순서로 정렬한다.

```text
최신 사용자 결정
→ 제품 정본 01~06 개정
→ 테스트 matrix 개정
→ 옛 기능 테스트 폐기·새 최소계약 테스트 작성
→ 그 뒤에만 제품 코드 수정
```

과거 보고서와 handoff는 역사 증거로 보존한다. 역사 문서를 고쳐서 과거 결과를 바꾸지 않는다.

## 2. 변경하지 않고 유지할 기반

- React·FastAPI·PostgreSQL·Windows 내부망 구조
- PIN·세션·CSRF·개인정보 보호
- 직원·수급자·인정·등급·계약 기본원장
- `row_version`, 변경 전후값, 행위자, 시각을 남기는 감사 기반
- 백업·복원·상태점검
- 원본 Excel 바이트와 처리이력 보존
- 기존 데이터는 확인·백업 전 물리삭제하지 않는 원칙
